# Hotel Reservation System using JDBC

A simple console-based **Hotel Reservation System** developed using **Java, JDBC, and PostgreSQL**.  
This project demonstrates how Java applications can connect to a PostgreSQL database and perform **CRUD (Create, Read, Update, Delete)** operations using JDBC.

## Technologies

- Java
- JDBC
- PostgreSQL
- SQL
- Git
- GitHub

## Features

- Connect Java application with PostgreSQL database
- Create a new hotel reservation
- View all reservations
- Get room number using reservation details
- Update reservation details
- Delete a reservation
- Retrieve data from PostgreSQL
- Execute SQL queries using JDBC
- Perform CRUD operations
- Handle SQL and database exceptions
